About this project

Hi, I'm Lorenzo, an Italian high school student studying computer science. I'm learning to write software, and I like small projects where I can follow the whole thing from start to finish.

I created OmniTools to put what I'm learning into practice. I wanted something small and complete that I could actually use, instead of a collection of isolated exercises.

The idea is simple: a handful of practical tools in one place, with a clear interface and no unnecessary complexity. Each tool does one job and runs in your browser, so nothing you type or upload is sent to a server.

This project is also my final project for CS50x, part of my current path into computer science.
